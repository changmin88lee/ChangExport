# 창Export 형상 엔진 기준선

## 필터 형상 엔진(FGE)

- 정식 명칭: 필터 형상 엔진
- 영문명: Filtered Geometry Engine (FGE)
- 복원 기준: Git 태그 `V30`, 커밋 `986b8d8`
- 제품 버전: `Beta 0.12.6`
- 동작: Revit 임시 필터·Part·식별색을 적용한 필터 DWG를 최종 형상 원본으로 사용한다.

FGE는 유형 이름·재료 필터를 강하게 반영하지만, 임시 Part와 링크 표시 재지정 때문에 원본 Revit 시트의 해치, 가림, 복합벽 끝단과 선 정리가 달라질 수 있다.

## 네이티브 형상 엔진(NGE)

- 정식 명칭: 네이티브 형상 엔진
- 영문명: Native Geometry Engine (NGE)
- 최초 개발 브랜치: `codex/native-geometry-engine`
- 최초 제품 버전: `Beta 0.13.0`
- 동작: Revit 기본 시트 DWG만 최종 형상 원본으로 사용한다. 임시 필터 DWG의 객체는 최종 결과에 복사하지 않고, 유형·재료 분류 증거만 Native 객체에 전사한다.

전사는 다음 안전 조건을 따른다.

1. 위치와 형상이 동일한 객체를 우선한다.
2. 선 분할이 다르면 같은 직선 위에서 Native 선 전체가 하나의 필터로 완전히 덮일 때만 인정한다.
3. 재료 Part는 원래 Revit 카테고리의 Native 레이어에만 전사한다.
4. 서로 다른 필터가 같은 형상에 충돌하면 재지정하지 않고 진단에 기록한다.
5. 필터 DWG에만 존재하는 Part 선·해치·객체는 최종 DWG에 추가하지 않는다.
6. Native에만 존재하는 링크 해치, 문·창 가림, 마스킹, 끝단 마감은 제거하지 않는다.

## 유지해야 하는 핵심 기능

- 유형 이름 필터
- 재료 필터
- 전역폭선
- 객체 색상 정책
- 모형공간 변환
- 여러 시트 병합
- 패밀리 블록 정리
- 문자 복원
- 카테고리·하위 항목 레이어 매핑
- 링크 객체와 링크 시트 출력
- 해치·마스킹·레이어 이름 정규화

## 복원 원칙

NGE 실제 Revit 시험에서 핵심 기능 또는 도면 표현 회귀가 확인되면 `main`을 강제로 되돌리지 않는다. `V30`을 기준으로 새 복구 브랜치를 만들거나 NGE 브랜치를 폐기하여 FGE 소스와 이력을 보존한다. DLL·ZIP·RVT·DWG는 Git 추적 대상이 아니므로 필요한 역사 설치본은 별도 패키지로 보존한다.
